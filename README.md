# 🛒 Swift POS

Modern Point of Sale (POS) web application built with React + Vite.

## ✨ Features

- Product management
- Transaction system
- Real-time stock updates
- Checkout modal
- Payment methods
- Change calculation
- Invoice search
- Low stock indicator
- Responsive modern UI

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/cakramhndr/swift-pos-web.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
